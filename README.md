# Veda Internship – Task 4:Digital Clock

A simple and responsive digital clock built using **HTML5, CSS3, and JavaScript**.

## 📌 About the Project

This project displays the current time in **HH:MM:SS** format and automatically updates every second.

It was created as **Task 4** of my Web Development Internship to practice JavaScript Date objects, timers, DOM manipulation, and dynamic content updates.

## ✨ Features

* Displays the current hours, minutes, and seconds
* Automatically updates every second
* Uses leading zeros for single-digit values
* Simple and responsive design
* Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
digital-clock/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. The digital clock will start automatically.

## 🎯 Learning Objectives

Through this project, I practiced:

* JavaScript `Date` object
* `setInterval()`
* DOM selection and manipulation
* Updating webpage content dynamically
* Formatting time with leading zeros
* Basic responsive styling
